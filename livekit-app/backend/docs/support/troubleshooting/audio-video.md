# Audio and video troubleshooting

## No microphone detected

1. Grant browser permission when prompted.
2. macOS: System Settings → Privacy → Microphone — allow the browser.
3. Select the correct input device from the mic menu in Pre-join or control bar.

## No camera

Same steps as microphone; check camera privacy permissions.

## Echo or feedback

Only one device in the same room should have speakers unmuted. Use headphones when possible.

## Choppy video

Close other tabs; disable HD if available; reduce video effects complexity.
