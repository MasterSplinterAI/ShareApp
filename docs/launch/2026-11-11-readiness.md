## What changed

- Checkout now prevents duplicate subscriptions, reuses pending sessions, and safely replaces an unpaid session when the customer changes plans. Existing subscribers use Stripe's portal.
- Subscription webhooks fetch authoritative Stripe state and map the actual price to the local plan. Unpaid Checkout does not grant paid access; cancellation restores usable Free; stale events cannot restore canceled entitlements. Resume uses mutually exclusive Stripe cancellation parameters correctly.
- Automatic overage charging is disabled in the platform settings. Known cycle overlap, rate snapshot, ledger finalization, and collection/retry issues need a separate accounting repair before enabling it.
- Guest controls require current membership in the meeting's organization. A role from another organization or stale/disabled account cannot grant provider administration.
- Password-reset links use trusted canonical configuration. Incorrect current-password validation no longer logs the user out, while expired authentication still redirects to sign-in.
- Prejoin microphone/camera errors are visible. Per the owner’s confirmed preference, new meetings and direct calls save transcripts by default. Hosts can opt out; existing policy values and stored records are preserved. Prejoin notices disclose on/off status (or explain the default if unavailable), link to privacy information, and provide hosts a settings link. Notices are translated in all seven supported UI locales; privacy and FAQ wording match the default.
- Agent candidate: admin-only legacy global voice changes, explicit provider credential requirements, pinned verified SDK versions, direct signal forwarding, application shutdown budget that drains final cost reports (SDK/native RTC disconnect can occur before this callback), and credential-free Docker runtime checks.
- Follow-up: direct Python startup replaces the reproducibly failing Cloud shell command. Agent translation usage counts accepted PCM frames, including transmitted silence but excluding no-frame gaps. Participant usage uses validated source timestamps and session SIDs, so delayed disconnects/reconnects do not distort duration. Late STT rows reconcile idempotently, with bounded backlog recovery on arrival. Accepted cost ingestion remains acknowledged if quota mirroring fails, avoiding a new retry-induced duplication hazard.
