# Live translation

Parley can translate spoken audio in real time during meetings when the feature is enabled for your organization plan.

## Enabling translation

Translation is toggled from the meeting control bar when your plan includes it. Each participant hears translation in their selected language where supported.

## Supported languages

Language availability depends on plan and server configuration. If a language is missing, contact support with the meeting room name and desired languages.

## Troubleshooting

- Translation not starting: ensure translation is enabled before or after join; refresh if stuck (see troubleshooting/translation-stuck.md).
- Poor quality: check network connection; wired connection recommended for hosts.
