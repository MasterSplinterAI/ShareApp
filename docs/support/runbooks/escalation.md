# Escalation runbook

Escalate to human ops (Telegram) without auto-reply when:

- Billing disputes, chargebacks, refund requests
- Legal, privacy, or law enforcement requests
- Harassment, abuse, or security incidents
- Account takeover suspicion
- Data deletion requests (GDPR-style)

Set ticket status to **escalated** and assign to the on-call admin email.

Do not share internal logs or other customers' data in user-facing messages.
